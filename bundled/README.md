# Bundled Stratus Link

Put the latest `StratusLink.exe` in this folder. The installer copies it next to the app, and the
Companion's tray menu can then start and stop it.

Get the file from the Stratus OPs **Connections** page (while signed in): download the Stratus Link zip,
unzip it, and upload the single `StratusLink.exe` from inside it here. Do not upload the zip itself.
Only the file named exactly `StratusLink.exe` is packaged; this README is not.
